# Vimigo Company OS Setup

This repository backs Vimigo's AI class.
The prompts for the session are given to you by the facilitator.
Each one is standalone: you paste it into the Claude app's Code tab (or the Codex app).
Nothing here needs to be downloaded or run. `setup/START.md` and `setup/ZO.md` exist only so earlier pasted prompts keep working: they hold the same standalone text the facilitator gives out.
