# Vimigo Company OS Setup

This repository backs Vimigo's AI class. The three prompts for the session
are given to you by the facilitator. Each one is a standalone text: you paste
it into the **Claude** app's **Code** tab (or the **Codex** app) and press
Enter. Nothing is fetched from this page by those prompts.

## Earlier prompts

The `setup/` folder only exists for earlier prompts that still point at it.
It will be removed after the V003 event ends on 5 Oct 2026. If you were given
one of these before, paste the whole line into the **Code** tab or the
**Codex** app (not Claude chat, ChatGPT chat, or Cowork):

```

```
