# Step 5 on a Mac

The same `node` commands in the README do the whole step. This page only
says where things tend to be.

- **Their Second Brain:** `~/Second Brain`. Write the document and
  `Submission/files/` there, never in Documents, Desktop or iCloud Drive.
- **Their conversations:** `node lib/sources.js list --since "<opensAt>"`
  already finds Claude Code (`~/.claude/projects`), Codex
  (`~/.codex/sessions`) and Cowork
  (`~/Library/Application Support/Claude`). Use its list rather than looking
  yourself.
- **Files they may have made:** the folders their notes or conversations
  name; otherwise Desktop, Downloads and Documents — screenshots land on the
  Desktop by default. Only files from the event days that belong to the
  project.
- **Asking permission:** macOS may ask whether your app can see Desktop,
  Documents or Downloads. That is expected; if they say no, leave those
  files out and name them in the list instead. Never ask them to change
  privacy settings for this.
- **iCloud Drive:** with "Optimise Mac Storage" on, a file can live only in
  iCloud. If it will not copy, leave it out and name it in the list.
- **Copy with your own file tools**, keeping the original where it is. A path
  with spaces needs quotes in any command.
